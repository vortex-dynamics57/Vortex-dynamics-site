VORTEX DYNAMICS WEBSITE
=======================

Files:
- index.html: responsive website homepage and all five division sections
- assets/: uploaded VD logo reference images

Preview:
Open index.html in a browser. Some browsers restrict local image loading in file previews;
if that happens, use the ZIP with a static host.

Publish free with GitHub Pages:
1. Sign in or create a GitHub account.
2. Create a new public repository, e.g. vortex-dynamics.
3. Upload the contents of this ZIP (index.html and assets folder) to the repository root.
4. Open repository Settings > Pages.
5. Choose deployment from the main branch and root folder, then Save.
6. Wait for GitHub Pages to publish and open the provided URL.

Notes:
- No paid domain is required.
- Don't add personal address, phone number, school, or other private information.
- This is a static website; no backend or private account data is included.
